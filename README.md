# ЛР 5. Python + SQLite — Вариант 19

## Тема
Выставочные стенды

## Таблица `stands`
| Поле | Тип | Смысл |
|---|---|---|
| id | INTEGER PRIMARY KEY | Номер записи |
| name | TEXT | Название стенда |
| category | TEXT | Тема выставки |
| value | INTEGER | Ширина стенда в сантиметрах |

## Запуск
python main.py

## Выполненные операции
- Создана таблица `stands`, добавлено 8 записей (категории: Технологии, Искусство, Еда)
- Выведены все записи
- Выборка `category = 'Технологии'`
- Числовой фильтр `value > 80`
- Сортировка `ORDER BY value ASC`
- UPDATE: у id=1 ширина изменена с 60 на 90 см
- DELETE: удалена запись id=8
- Данные сохраняются в `app.db` после перезапуска
